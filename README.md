# 📄 Resume Classification System

## Overview
The Resume Classification System is a Machine Learning and Natural Language Processing (NLP) project designed to automatically classify resumes into predefined job categories based on candidate skills, experience, and qualifications.

This system helps recruiters and HR professionals efficiently filter and categorize resumes, reducing manual effort and improving recruitment accuracy.

## Objectives
- Automate resume screening and classification.
- Categorize resumes into relevant job roles.
- Improve recruitment efficiency.
- Reduce manual processing time.

## Features
- Resume text extraction and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering using NLP techniques
- Multiple Machine Learning models
- Automatic resume categorization
- Streamlit-based deployment

## Technologies Used

- NLTK

## Machine Learning Models Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Best Performing Model
Decision Tree Classifier was selected as the final model due to its excellent classification performance and high accuracy.

## Project Workflow

3. Exploratory Data Analysis (EDA)

5. Feature Extraction
6. Model Training
7. Model Evaluation
8. Deployment using Streamlit
